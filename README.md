# Magyar Vizsga Tréner

Бесплатный тренажёр для подготовки к венгерскому экзамену по культуре (**magyar kulturális ismereti vizsga**).

Открыть: https://koppalovamariia.github.io/magyar-vizsga/

- 6 тем официальной программы экзамена, по учебному материалу Budapest Főváros Kormányhivatala (segédanyag, сентябрь 2026)
- диагностика, уроки, практика, интервальные повторения, чеки и итоговый экзамен в формате настоящего
- каждое венгерское слово можно навести или нажать и увидеть перевод в контексте и разбор грамматики
- прогресс хранится в браузере

Не является официальным материалом. Источники иллюстраций перечислены на странице «Настройки → Источники».
